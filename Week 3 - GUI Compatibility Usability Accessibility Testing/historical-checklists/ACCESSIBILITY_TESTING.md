## Accessibility checklist

| Test ID | Page / criteria | Test action | Expected result | Actual result | Status | Evidence / defect ID |

| ACC-01 | Keyboard access | Navigate using Tab, Shift+Tab and Enter | Interactive controls are keyboard accessible |  | Not run |  |
| ACC-02 | Focus indicator | Tab through links and buttons | Keyboard focus is visible |  | Not run |  |
| ACC-03 | Colour contrast | Inspect text/background contrast using accessibility tool | Normal text meets 4.5:1; large text meets 3:1 (WCAG AA) |  | Not run |  |
| ACC-04 | Form labels | Inspect accessible names and label associations | Inputs have meaningful accessible labels |  | Not run |  |
| ACC-05 | Alternative text | Inspect images if present | Meaningful images have text alternatives; decorative images are ignored |  | Not run |  |

| ACC-07 | Semantic HTML | Inspect headings, buttons and links | Elements convey appropriate structure and purpose |  | Not run |  |
| ACC-08 | Error identification | Submit invalid form data | Errors are identifiable in text |  | Not run |  |
