# PyTodo Pro · Week 3 accessibility testing

Chromium desktop ran axe-core against rendered screen states with WCAG tags wcag2a, wcag2aa, wcag21a, wcag21aa and wcag22aa. Playwright supplemented those checks with actual keyboard events, DOM/CSS measurements and an accessibility tree snapshot. The sampled checks cover selected criteria and page states.
