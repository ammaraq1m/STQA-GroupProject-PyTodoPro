## Evidence boundaries

Published Week 1–2 outcomes were reconciled at the report-row level. The original recorded artifacts support case-level checks for Weeks 3–6. Week 8 performed repository and artifact review without producing new application execution results. The Week 7 evidence baseline is revision `17f54e1`. The application source, templates, CSS and application dependency file at the reviewed checkout match that revision. Local SQLite test files, fixtures, browser versions and clock settings constrain generalisation. Fixture-specific failure observations and source weaknesses support the readiness decision. Likelihood, production exposure and impact beyond observed behaviour are assessment judgments.
